# E-Commerce Store (Django Project)

A full-stack e-commerce web application built with Python and Django, featuring user authentication, product catalog filtering, cart management, checkout processing, and order tracking.

## Tech Stack
* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite / PostgreSQL

## Features
* User registration and role-based login system.
* Category-based product filtering (Electronics, Home, Apparel, etc.).
* Dynamic cart calculations and item quantity updates.
* Secure checkout flow supporting Cash on Delivery (COD).
* Customer reviews, ratings, and user order history tracking.
