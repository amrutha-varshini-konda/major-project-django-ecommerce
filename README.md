# Django E-Commerce Project

A fully-featured e-commerce web application built with Python and Django. This project features user authentication, product catalogs, shopping cart functionality, and order management.

## 🚀 Features
* User registration, login, and authentication
* Product listing, categories, and detailed views
* Shopping cart and secure checkout process
* Admin dashboard for product and order management
* Responsive design with HTML/CSS templates

## 🛠️ Tech Stack
* **Backend:** Python, Django
* **Database:** MySQL / SQLite
* **Media Management:** Pillow (Python Imaging Library)
* **Version Control:** Git & GitHub
